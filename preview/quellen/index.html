Wie diese Seite arbeitet

  • Primärquellen zuerst. Behörden, Gerichte, Institute, Parlamentsdokumente — Medienberichte nur, wenn sie Wortlaut oder Zahlen dokumentieren.
  • Jede Quelle wird archiviert. Beim Zitieren wird der Volltext gespeichert und mit SHA256 gefingerabdruckt. Auch wenn das Original später verschwindet, bleibt der Beleg prüfbar.
  • Zitate belegen die Aussage, nicht den Sachverhalt. Ein Zitat zeigt, was gesagt wurde — nicht, ob es stimmt.
  • Korrekturen werden sichtbar. Wird eine Quelle widerlegt oder eine Zahl korrigiert, wird die betroffene Szene angepasst.
  • Betreiber-Transparenz. Diese Seite ist ein privates, unabhängiges Projekt — keine Parteifinanzierung, keine Auftragsarbeit. Quellen-Archiv und Code sind öffentlich einsehbar.
